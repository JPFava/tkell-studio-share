# TKell Design Studio

Download the newest package from the releases page. No GitHub account is required.

https://github.com/JPFava/tkell-studio-share/releases/latest

Current package: 1.4.1. That link always opens the newest release.

- `TKell-Design-Studio-Guide.pdf` opens on its own. Start there. The first page says **New in 1.4.1**.
- `TKell-Design-Studio.zip` is the program. It asks for a password. The password is in the note from TKell. It is not published here.

Do not attach the zip to Gmail. Gmail rejects it as a dangerous file. Send this page’s link, and the password, as ordinary text. The designer downloads the files.

Unzip, then follow the guide. Appendix A installs the STEP modeler on Windows or Mac. Version 1.4.1 keeps a circle’s first tangent when the third click adds another one. The radius or the center may move. Dialog numbers sit on a light field. Clicking a tool that is already on ends it, the same as Esc.
