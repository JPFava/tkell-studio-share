# TKell Design Studio

Download the newest package from the releases page. No GitHub account is required.

https://github.com/JPFava/tkell-studio-share/releases/latest

Current package: 1.4.0. That link always opens the newest release.

- `TKell-Design-Studio-Guide.pdf` opens on its own. Start there. The first page says **New in 1.4.0**.
- `TKell-Design-Studio.zip` is the program. It asks for a password. The password is in the note from TKell. It is not published here.

Do not attach the zip to Gmail. Gmail rejects it as a dangerous file. Send this page’s link, and the password, as ordinary text. The designer downloads the files.

Unzip, then follow the guide. Appendix A installs the STEP modeler on Windows or Mac. Version 1.4.0 uses click-click drawing. Line, Circle, Fillet, Chamfer, and Offset repeat until Esc. Snap stays on unless Ctrl is held. Model tools open a dialog, and accepted features collect in a list.
