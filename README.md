# TKell Design Studio

Download the newest package from the releases page. No GitHub account is required.

https://github.com/JPFava/tkell-studio-share/releases/latest

Current package: 1.4.3. That link always opens the newest release.

- `TKell-Design-Studio-Guide.pdf` opens on its own. Start there. The first page says **New in 1.4.3**.
- `TKell-Design-Studio-Install.zip` is the program. It asks for a password. The password is in the note from TKell. It is not published here.

Do not attach the zip to Gmail. Gmail rejects it as a dangerous file. Send this page’s link, and the password, as ordinary text. The designer downloads the files.

Expand the zip, then double-click the installer. Windows: `Windows - Double Click to Install.bat` (do not use Run as administrator). Mac: `Mac - Double Click to Install.command`. The first time, if macOS blocks it, right-click → Open → Open. The installer downloads Node.js 22 for that computer and puts Start TKell Studio and Update TKell Studio on the Desktop. Leave that window open while the studio is running.

1.4.3 fixes Windows start. Version 1.4.2 stopped with “spawn vite ENOENT.” Close that window, double-click Update TKell Studio, then Start TKell Studio again. Or expand this zip and double-click the installer. It upgrades in place.

When a newer version exists, the studio shows Update. Double-click Update TKell Studio on the Desktop. It keeps the STEP modeler.

If the first note under the title is not “New in 1.4.3,” the download is an older file.
